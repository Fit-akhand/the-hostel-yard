# THE HOSTEL YARD — Frontend

Premium operations console for hostel, PG and property management. It talks only to the existing Express API and never stores JWT tokens in `localStorage`.

## Setup

```bash
cd frontend
cp .env.example .env
npm install
npm run dev
```

The Vite app prefers `http://localhost:5173` and will use the next free port (for example `5174`) if that is taken.

Local API calls use **same-origin** `/api`. Vite proxies `/api` to `http://localhost:5000` so the browser never talks to the backend origin directly (no CORS). Do not set `VITE_API_URL` to `http://localhost:5000/api` during development.

## Environment

| Variable | Purpose |
| --- | --- |
| `VITE_API_URL` | API prefix. Default `/api` (proxied to `http://localhost:5000` in `vite.config.js`) |

Do not put secrets in the frontend. Authentication uses the HttpOnly `accessToken` cookie set by `POST /api/auth/login`.

## Authentication

- Cookie: `accessToken` (HttpOnly). Axios uses `withCredentials: true`.
- Session bootstrap: `GET /api/auth/me`
- Logout: `POST /api/auth/logout` then clear client state
- 401 responses clear the session (except login failures)

Owner setup:

1. `POST /api/auth/setup-owner`
2. Confirm OTP via `POST /api/auth/verify-setup` (OTP is logged in the **backend** terminal in development)
3. Sign in

Password reset uses `/reset-password?token=...` as generated by the backend.

Invitation URLs expected by the backend:

- `/tenant/accept-invitation?token=`
- `/manager/activate/:token`
- `/staff/activate/:token`

## Roles

`BUSINESS_OWNER`, `LANDLORD`, `PROPERTY_MANAGER`, `STAFF`, `TENANT`

Tenants use a separate portal under `/tenant`. Staff and owners use `/dashboard`.

Frontend permission checks are UX only. The API remains authoritative.

`GET /api/auth/me` does not return assignment permissions. For managers and staff the UI shows modules that exist in the backend capability lists (`MANAGER_ALLOWED_PERMISSIONS` / `STAFF_ALLOWED_PERMISSIONS`). Individual actions still fail with the API’s 403 when the assignment does not include that permission.

Business owners and landlords are treated as fully capable in the UI because the backend does not assign them a permission array.

## API integration

All HTTP goes through `src/services/apiClient.js`. Feature modules live in `src/services/apis.js`. React Query caches list/detail queries and invalidates after mutations.

Currency is formatted with `en-IN` as INR (`₹1,25,000`). Dates use `Asia/Kolkata`.
